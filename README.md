# README

## Project Name
Alzikrayat

## Description
A photo-sharing web app where users can register, upload photos, browse a gallery and comment on photos.

## Technologies
PHP (MVC), MySQL, HTML, CSS, Bootstrap 5, JavaScript

## How to Run
1. Copy the project folder to `C:\xampp\htdocs`.
2. Start Apache and MySQL from XAMPP.
3. Create a database named `alzikrayat` in phpMyAdmin with the tables Users, Photos and Comments.
4. Open `http://localhost/alzikrayat/public/` in the browser.
